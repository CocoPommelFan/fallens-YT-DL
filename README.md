# Youtube video/audio downloader


## Installation:

1. In PowerShell `winget install Python.Python.3.12`
2. [Download](https://github.com/denoland/deno/releases/download/v2.7.5/deno-x86_64-pc-windows-msvc.zip) and copy deno.exe in deno_bin
3. `py -3.12 venv venv`
4. `.\venv\Scripts\activate`
5. `pip install -r requirements.txt`
6. *start.bat*
